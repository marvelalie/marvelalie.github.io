# marvelalie.github.io

Portfolio website of Marvela Rusly, live at https://marvelalie.github.io.

Plain HTML and CSS, no build step:

- `index.html`: all the page content (text, links, sections)
- `style.css`: colors, fonts and layout
- `images/`: photos and graphics

To change text, edit `index.html` on GitHub and commit; the site updates in about a minute.
